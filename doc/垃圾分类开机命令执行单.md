# 香橙派 AI Pro：垃圾分类开机命令执行单

适用工程：`/root/ros2_robot_arm`。根据已经实际跑通的双终端流程整理，日期：2026-09-23。

## 一、开机前

- 接好机械臂配套电源、开发板电源、40PIN 排线及 USB 摄像头；排线需要重插时先断电。
- 机械臂扩展板开关置 ON，底座固定，活动范围清空。程序启动会自动复位，识别到目标后会自动抓取；手离开工作区。
- 保持标定时的底座、摄像头和地图相对位置。位置变化后需要重新标定。
- 开发板开机并等待系统启动。当前地址为 `192.168.137.100`。电脑连接开发板的以太网地址应为 `192.168.137.1`；如沿用 Windows 网络共享，请保持原共享配置。

模型和依赖均已安装，本地运行垃圾分类不需要外网。无需重新安装、下载模型、编译或启动 Jupyter。

## 二、窗口 1：运动学服务

在 Windows PowerShell 或命令提示符运行：

```powershell
ssh HwHiAiUser@192.168.137.100
```

输入 SSH 密码，进入香橙派后执行：

```bash
sudo -i
```

输入 sudo 密码，出现 `root@orangepiaipro` 提示符后执行：

```bash
cd /root/ros2_robot_arm
source setenv.sh
ros2 run dofbot_moveit dofbot_server
```

保持窗口 1 运行，不关闭。它负责运动学计算，不直接驱动舵机。

## 三、窗口 2：垃圾分类

另开一个 Windows PowerShell 或命令提示符，执行：

```powershell
ssh HwHiAiUser@192.168.137.100
```

登录香橙派后执行：

```bash
sudo -i
```

出现 root 提示符后执行：

```bash
cd /root/ros2_robot_arm
source setenv.sh

if [ -f /usr/local/Ascend/ascend-toolkit/set_env.sh ]; then
    source /usr/local/Ascend/ascend-toolkit/set_env.sh
elif [ -f /usr/local/Ascend/ascend-toolkit/latest/set_env.sh ]; then
    source /usr/local/Ascend/ascend-toolkit/latest/set_env.sh
fi

ros2 service list | grep trial_service
```

确认显示 `/trial_service`，再执行下面这条启动命令。运行前放好一个配套图案演示块，移开手，清空其余障碍物；不要在程序运行时伸手放取物体。

```bash
ros2 run dofbot_garbage_yolov5 block_cls
```

保持两个窗口运行。不要同时启动第二个分拣进程、堆叠程序或相机校准 Notebook。

## 四、怎么看是否正常

- `load model ... success`：模型已加载。
- `Finish Robot Arm Position Reset!`：程序已完成复位指令序列。
- `read image from camera successfully: True`：摄像头能读取画面。
- `msg is: {}`：当前没有输出识别目标，空场时可能正常；不一定是程序故障。
- 出现目标信息并执行抓取：观察抓取位置和放置位置是否正确。

使用配套图案演示块；当前标签包括 Fish_bone、Newspaper、Syringe，不代表能识别任意真实垃圾。

此前 NPU 有 Alarm，但已实际完成分拣；这不代表告警已消除。如出现 NPU 推理错误或运行中断，保留完整报错再排查。`torchvision` 图像扩展警告此前未阻止程序运行。

## 五、正常停止与关机

1. 等本轮抓取完成、机械臂停止。
2. 窗口 2 按 `Ctrl+C` 停止垃圾分类，回到提示符后，窗口 1 按 `Ctrl+C` 停止运动学服务。出现 `KeyboardInterrupt` 或 `[ros2run]: Interrupt` 是手动中断的表现。
3. 确认机械臂处于稳定、不会因断电下坠的姿态，再关闭机械臂电源。
4. 在任意香橙派 SSH 终端执行：

```bash
sudo shutdown -h now
```

SSH 随后会断开；等待开发板完成关机后再拔开发板电源。不要在系统仍运行时直接拔电。若姿态不稳定，先停程序并将机械臂妥善支撑后再断电。

异常碰撞或失控时立即关闭机械臂电源；`Ctrl+C` 不会可靠撤销已经发送给扩展板的运动指令，不能代替硬件停机。

## 六、常见情况

- SSH 连不上：检查板卡是否开机、网线及电脑以太网地址；有屏幕时用 `ip -brief addr` 查询板卡地址，若变化则修改 SSH 命令。
- 没有 `/trial_service`：查看窗口 1 是否正常启动，先处理其报错。
- 摄像头打不开：关闭占用相机的 Jupyter 内核、其它分拣或堆叠进程，再启动。
- 换了机械臂、摄像头或地图位置：重新标定，保存后恢复 `CALIB_MODE = False` 并编译。
- 每次新开 SSH 都需要加载环境；不要只运行最后一条 `ros2 run`。

最近成功使用的标定参数为 `x=89`、`y=129`、`thresh=129`，仅供核对，不需要每次开机重新写入。
